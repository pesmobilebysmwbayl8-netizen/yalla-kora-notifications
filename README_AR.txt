يلا كورة — حزمة إعداد إشعارات Firebase Cloud Messaging للويب

الملفات:
- index.html: نسخة يلا كورة مع زر تفعيل الإشعارات وصفحة تعرض رمز جهاز FCM.
- firebase-messaging-sw.js: خدمة الخلفية التي تستقبل رسائل FCM وتعرض الإشعارات.

متطلبات التشغيل:
1) يجب نشر الملفين على نفس الموقع عبر HTTPS، ويجب أن يكون firebase-messaging-sw.js في جذر الموقع (مثل https://example.com/firebase-messaging-sw.js).
2) افتح الموقع من متصفح يدعم Firebase Web Messaging، ثم افتح صفحة «إشعارات المباريات» واضغط «تفعيل الإشعارات» ووافق على الإذن.
3) سيظهر رمز جهاز FCM. احتفظ به بشكل خاص؛ لا تنشره علنًا.
4) اختبر إرسال إشعار من Firebase Console إلى رمز الجهاز بعد إكمال إعدادات Cloud Messaging.

مهم جدًا:
- هذه الحزمة تجهّز جهة الاستقبال وتُظهر رمز الجهاز، لكنها لا ترسل إشعارات المباريات تلقائيًا من نفسها.
- الإرسال قبل المباراة أو عند بدايتها يحتاج خدمة خلفية آمنة/وظيفة مجدولة تستخدم صلاحيات Firebase Admin أو FCM HTTP v1. لا تضع مفتاح خدمة Admin أو بيانات اعتماد الخادم داخل HTML.
- هذا حل لإشعارات الويب. لا نضمن عمله داخل APK/WebView بعد إغلاق التطبيق؛ دعم الإشعارات بالخلفية يختلف حسب أداة التغليف ونظام Android. إذا لم يدعم WebView خدمة Web Push، يلزم غلاف Android أصلي يدعم FCM.
- لا تفتح index.html من file:// أو من ملفات الهاتف مباشرة؛ يجب استضافته عبر HTTPS لكي تعمل Service Workers.
- لا تغيّر قواعد Realtime Database لتسمح بالكتابة العامة بغرض تخزين الرموز.
